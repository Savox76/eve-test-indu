# New Eden Foundry v0.0.5-preview.27

## Neu hinzugefügt

- Ein Frontend-Vertragstest bildet den installierten Neustart mit einem frischen Cache ohne eigenes Ablaufdatum ab und verlangt, dass der Desktop-Kern sowie gespeicherte Charaktere freigegeben werden.

## Geändert

- Der Startvertrag für lokale Cache-Daten ist jetzt in Backend, Windows-Hülle und Frontend identisch.

## Behobene Fehler

- Nach einer Synchronisierung und einem anschließenden Neustart konnte die Oberfläche einen gültigen frischen Cache ohne Ablaufdatum ablehnen. Dadurch erschien fälschlich „Statusabfrage nicht möglich“ und Charaktere, Assets sowie alle Synchronisationsbefehle blieben gesperrt, obwohl Sidecar und Datenbank bereit waren.

## Bekannte Einschränkungen

- Diese Preview besitzt noch keine produktive Windows-Codesignatur. SmartScreen kann deshalb weiterhin vor einem unbekannten Herausgeber warnen; eine echte Virenerkennung darf nicht umgangen werden.
- Paket 22 benötigt weiterhin das vollständige Windows-A0-Protokoll auf dem Zielgerät.

## Update und Datenbankmigration

- Das Datenbankschema bleibt bei Version 9; der vorhandene `data`-Ordner muss beibehalten werden.
- `.26` vollständig schließen und `.27` installieren. Die Installer-Option zum Löschen der Anwendungsdaten muss abgewählt bleiben.
- Portable vollständig entpacken und den bisherigen `data`-Ordner vor dem ersten Start in den neuen portablen Ordner übernehmen.
