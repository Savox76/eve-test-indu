# New Eden Foundry v0.0.1-preview.2

Diese Vorabversion ergänzt die Design Preview um eine portable Windows-Ausgabe. Die Oberfläche und ihre Daten bleiben gegenüber `v0.0.1-preview.1` fachlich unverändert und vollständig synthetisch.

## Neu hinzugefügt

- Portable Windows-ZIP, die vollständig entpackt und ohne Installation oder Administratorrechte gestartet werden kann.
- Deutsch-englische Nutzungshinweise direkt im portablen Paket.
- Eigene SHA-256-Prüfsummen für Installer und portable ZIP.
- Automatische Inhaltsprüfung der portablen ZIP vor dem Merge und vor der Veröffentlichung.

## Geändert

- Jedes künftige Windows-Release veröffentlicht verbindlich sowohl einen NSIS-Installer als auch eine portable ZIP direkt auf der GitHub-Release-Seite.
- Der Release-Workflow liest Version, Tag, Release Notes und Prerelease-Status aus der jeweiligen Version, statt auf eine einzelne Preview festgelegt zu sein.
- Die sichtbare Versionsnummer wurde auf `v0.0.1-preview.2` aktualisiert.

## Behobene Fehler

- Keine.

## Bekannte Einschränkungen

- Es besteht noch keine Verbindung zu EVE SSO, ESI oder SDE.
- Sidecar, SQLite-Datenbank, Synchronisierung, Berechnungen und Updater sind noch nicht implementiert.
- Sämtliche Fachmodule außerhalb der Übersicht sind ausschließlich visuelle Platzhalter.
- Installer und portable EXE sind noch nicht code-signiert. Windows kann deshalb eine SmartScreen-Warnung für einen unbekannten Herausgeber anzeigen.
- Die portable Ausgabe benötigt die Microsoft Edge WebView2 Runtime, die auf unterstützten aktuellen Windows-10- und Windows-11-Systemen normalerweise bereits vorhanden ist.
- Die damalige Planung eines vom Programmordner getrennten Datenorts wurde mit ADR-010 ersetzt: Ab `v0.0.3-preview.1` liegt die Fachdatenbank unter `data` im Programmordner; Zugangsdaten bleiben im Windows-Anmeldespeicher.
- Nur Windows x64 wird in dieser Vorschau paketiert; Installation, Start, Deinstallation und portabler Start müssen auf einem Windows-Testgerät noch manuell bestätigt werden.

## Update und Datenbankmigration

- Es gibt weiterhin keine Nutzerdatenbank; eine Migration ist nicht erforderlich.
- Eine installierte `v0.0.1-preview.1` kann unverändert bestehen bleiben. Für die portable Variante das ZIP vollständig in einen eigenen Ordner entpacken und dort `New Eden Foundry.exe` starten.
