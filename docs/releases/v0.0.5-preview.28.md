# New Eden Foundry v0.0.5-preview.28

## Neu hinzugefügt

- Ein Rust-Vertragstest sichert mehrstufige Produktionsketten vom tiefsten Vorprodukt bis zum abschließenden Zielprodukt ab. Qualitäts- und Release-Workflow führen die Rust-Unit-Tests nun ausdrücklich vor dem Paketbau aus.

## Geändert

- Backend, Windows-Hülle und Frontend verwenden jetzt denselben Vertrag für die ausführbare Reihenfolge von Produktionsschritten.

## Behobene Fehler

- Mehrstufige Produktionsziele wurden korrekt in SQLite gespeichert, ihre anschließende Abfrage aber von der Windows-Hülle verworfen. Dadurch blieb die Liste der Produktionsziele leer oder meldete einen Abfragefehler. Bereits gespeicherte Ziele werden mit dieser Version wieder sichtbar.

## Bekannte Einschränkungen

- Diese Preview besitzt noch keine produktive Windows-Codesignatur. SmartScreen kann deshalb weiterhin vor einem unbekannten Herausgeber warnen; eine echte Virenerkennung darf nicht umgangen werden.
- Paket 22 benötigt weiterhin das vollständige Windows-A0-Protokoll auf dem Zielgerät.

## Update und Datenbankmigration

- Das Datenbankschema bleibt bei Version 9; der vorhandene `data`-Ordner muss beibehalten werden.
- `.27` vollständig schließen und `.28` installieren. Die Installer-Option zum Löschen der Anwendungsdaten muss abgewählt bleiben.
- Portable vollständig entpacken und den bisherigen `data`-Ordner vor dem ersten Start in den neuen portablen Ordner übernehmen.
