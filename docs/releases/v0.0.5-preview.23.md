# New Eden Foundry v0.0.5-preview.23

## Neu hinzugefügt

- Der installierte Windows-Pakettest legt vor dem zweiten Anwendungsstart einen vollständigen frischen Cache ohne eigenes Ablaufdatum an und prüft dessen Erhalt.
- Ein Rust-Vertragstest bildet genau den vom Python-Kern vorgesehenen Ready-Zustand dieses Datenbestands ab.

## Geändert

- Die sichtbare Versionsnummer lautet `v0.0.5-preview.23`.

## Behobene Fehler

- Ein vorhandener lokaler Datenkern konnte nach dem Versionswechsel mit `sidecar-ready-invalid` abgewiesen werden. Ursache war kein verlorener Datenordner: Der Python-Kern meldet Snapshots ohne ESI-Ablaufdatum innerhalb der ersten zwei Stunden gültig als `fresh`, während die Windows-Hülle für jeden frischen Snapshot fälschlich ein Ablaufdatum verlangte. Beide Seiten verwenden nun denselben Vertrag.

## Bekannte Einschränkungen

- Diese Preview besitzt noch keine produktive Windows-Codesignatur. SmartScreen kann deshalb weiterhin vor einem unbekannten Herausgeber warnen; eine echte Virenerkennung darf nicht umgangen werden.
- Paket 22 benötigt weiterhin das vollständige Windows-A0-Protokoll auf dem Zielgerät.

## Update und Datenbankmigration

- Das Datenbankschema bleibt bei Version 9. Der vorhandene Ordner `data` wird weder ersetzt noch zurückgesetzt.
- `.22` vollständig schließen und `.23` installieren. Die Installer-Option zum Löschen der Anwendungsdaten muss abgewählt bleiben.
- Portable vollständig entpacken und den bisherigen `data`-Ordner vor dem ersten Start in den neuen portablen Ordner übernehmen.
