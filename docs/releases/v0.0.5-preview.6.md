# New Eden Foundry v0.0.5-preview.6

## Neu hinzugefügt

- Vollständiger charaktergetrennter Blueprint-Sync und echte BPO/BPC-Bestandsansicht.
- ME, TE, verbleibende Läufe, Besitzer, Bereich, Datenalter, Suche, Filter, Sortierung und Pagination.
- Sichtbarer Neuanmeldehinweis für Charaktere mit fehlenden aktuellen Scopes oder Credentials.

## Geändert

- Jede EVE-SSO-Anmeldung fordert automatisch alle aktuell benötigten Berechtigungspakete an.
- Assets und Blueprints werden beim Programmstart und nach einer Charakteranmeldung im Hintergrund aktualisiert.
- Die sichtbare Versionsnummer lautet `v0.0.5-preview.6`.

## Behobene Fehler

- Scope-Erweiterungen bleiben nicht mehr als unklare Teilfunktion verborgen; der Charakter bleibt gespeichert und kann geführt erneut autorisiert werden.
- Unvollständige Blueprint-Läufe überschreiben keinen vollständigen lokalen Snapshot.

## Bekannte Einschränkungen

- Industrieaufträge und Jobkorrelation folgen in Paket 24.
- Die vollständige Windows-A0-Abnahme für Paket 22 bleibt offen.

## Update und Datenbankmigration

- Keine Datenbankmigration. Bestehende lokale Daten bleiben unverändert erhalten.
- Ein Charakter mit älterem Scope-Satz benötigt einmalig eine erneute Anmeldung über den sichtbaren Hinweis.

## Prüfsummen

Die SHA-256-Dateien werden zusammen mit Installer und portabler ZIP direkt an das GitHub Release angehängt.
