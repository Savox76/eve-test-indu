# New Eden Foundry v0.0.5-preview.25

## Neu hinzugefügt

Keine.

## Geändert

- Die Blueprint-Gruppen verwenden dieselbe transparente Tabellendarstellung und dieselbe Hervorhebung wie die gruppierte Asset-Ansicht.

## Behobene Fehler

- Blueprint-Namen wurden wegen einer fehlenden Komponentenklasse als breite graue Windows-Standardschaltflächen dargestellt.
- Beim Öffnen einer Blueprint-Gruppe wird der passende Suchfilter nun unmittelbar angewendet, ohne kurz den ungefilterten Bestand zu laden.

## Bekannte Einschränkungen

- Diese Preview besitzt noch keine produktive Windows-Codesignatur. SmartScreen kann deshalb weiterhin vor einem unbekannten Herausgeber warnen; eine echte Virenerkennung darf nicht umgangen werden.
- Paket 22 benötigt weiterhin das vollständige Windows-A0-Protokoll auf dem Zielgerät.

## Update und Datenbankmigration

- Das Datenbankschema bleibt bei Version 9; vorhandene Charaktere, Einstellungen, Pläne und Snapshots bleiben unverändert.
- `.24` vollständig schließen und `.25` installieren. Die Installer-Option zum Löschen der Anwendungsdaten muss abgewählt bleiben.
- Portable vollständig entpacken und den bisherigen `data`-Ordner vor dem ersten Start in den neuen portablen Ordner übernehmen.
